# Domain offering research

## Verified models

Lakay can start with a referral model in which the customer chooses and pays for a domain directly with a registrar. Name.com states that its affiliate programme pays commission on qualifying new customer domain registrations and is administered through Impact. This approach keeps registration, payment, renewals, DNS ownership, and support with the registrar.

For an in-product domain purchase flow, Name.com documents a registrar API intended for platforms and resellers, including domain availability and registration workflows. This would require a server-side integration, precise price display, registrant-consent handling, ownership and renewal support, and a real payment/legal review before activation.

GoDaddy documents an API Reseller plan that permits a business to sell domains under its own branding, but requires certification before production access. This is a genuine reseller model, not a simple affiliate link.

## Product recommendation

Start Lakay with **domain suggestions plus an affiliate handoff**. The user can search a proposed name, select an extension, complete the purchase on the registrar’s secure checkout, then return to Lakay to connect the DNS records. Present Lakay as a recommender and connection assistant, never as the registrar.

Move to embedded purchase only after a registrar partnership is approved and the product can safely support live prices, domain registrant data, terms, renewals, transfers, support, refund policy, tax handling, and DNS ownership lifecycle.
